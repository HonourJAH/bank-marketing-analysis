# Data

This project uses the Bank Marketing dataset from the UCI Machine Learning Repository: results of phone
marketing campaigns run by a Portuguese bank to sell term deposits (donated by S. Moro, P. Cortez and P. Rita).

Source: [add the exact UCI link here]

The file used is `bank-additional-full.csv` (41,188 rows, 21 columns, semicolon-separated). The CSV is not
included in this repository. To reproduce the project:

1. Download the dataset from the link above.
2. Save `bank-additional-full.csv` in this folder.
3. Run the notebooks in `/notebooks` in numbered order.
